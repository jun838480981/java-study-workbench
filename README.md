# ☕ 工作台 — 前端转 Java · 40 天通关之旅

一个为**有前端经验、Java 零基础**的开发者打造的游戏化 Java 学习工作台。

每天约 1 小时，跟着「学 → 练 → 测 → 过」的闭环打怪升级，40 天从 Hello World 走到 Spring Boot 项目部署。

> 线上地址：https://ws-b84c26d2c996a037.lightvela.tech/ （需所有者登录）

## ✨ 功能总览

### 📚 学习体系
- **40 天课程线**：完全对照[廖雪峰 Java 教程](https://liaoxuefeng.com/books/java)章节编排，从快速入门 → OOP → 泛型/集合/IO → Lambda/Stream/多线程 → Maven/Spring Boot → 若依实战
- **站内教程全文**：69 章廖雪峰教程正文内嵌阅读器，不跳外站、默认展开（底部保留原文链接与版权署名）
- **前端类比讲解**：每个知识点都附「前端怎么类比」，用 Vue/React 经验理解 Java 概念

### ⌨️ 练习与测验
- **站内代码编辑器**：行号、Tab 缩进、自动保存、可拖高（练习草稿本）
- **OnlineGDB 真运行**：复制代码 → 在线运行 → 对照预期输出，三步验证答案（静态站无法真编译 Java，诚实交底 😄）
- **通关测验**：80+ 道选择题，答对得 XP，错题自动进错题本
- **Boss 战**：Day 11 / 21 / 30 / 40 四场阶段大考，XP 奖励翻倍
- **错题重练**：点错题直接重测，答对移出错题本 +5 XP

### 🎮 游戏化
- **XP / 等级 / 称号**：见习勇者 → 语法学徒 → 咖啡骑士 → … → Java 大师（8 级）
- **17 枚成就徽章**：每枚都有实时进度条（如"连续打卡 2/3 天"）
- **每日挑战**：每天自动换目标（完美通关 / 完成测验 / 敲代码 / 记笔记），完成额外 +3~8 XP
- **打卡热力图**：GitHub 风格 12 周格子，偷懒一眼可见
- **毕业倒计时**：按当前节奏推算预计毕业日期

### 🧰 辅助工具
- **修行地图 / 历史回顾**：已通关的关卡可随时回看（未通关不可回看，防偷看答案）
- **资料库**：每日配套权威资料（官方文档 / 教程 / 工具），支持搜索
- **学习数据面板**：通关数、练码天数、正确率渐变条
- **番茄钟**：15/25/45 分钟三档，标签页标题倒计时，完成 +3 XP
- **踩坑笔记**：支持编辑、搜索（超 3 条自动出现搜索框）
- **深浅色主题**：右上角一键切换，选择自动记住
- **数据安全**：localStorage 本地存档 + JSON 导出/导入备份

## 🚀 本地运行

```bash
# 需要 Node 18+，推荐 pnpm
pnpm install
pnpm dev       # 开发模式
pnpm build     # 构建到 dist/
pnpm preview   # 预览构建产物
```

## 📁 项目结构

```
├── index.html              # 入口（标题 + 内联 SVG favicon）
├── src/
│   ├── App.tsx             # 主应用（状态机 / 面板 / 弹窗 / 游戏化逻辑）
│   ├── data.ts             # 40 天课程、里程碑、徽章、等级、测验题库
│   ├── exercises.ts        # 每日练习题（题目 / 参考答案 / 预期输出）
│   ├── resources.ts        # 每日配套资料链接（真实抓取验证）
│   ├── lxfContent.ts       # 69 章廖雪峰教程全文（静态快照）
│   ├── LxfReader.tsx       # 教程阅读器（轻量 markdown 渲染）
│   ├── CodeEditor.tsx      # 代码编辑器（行号 / 自动保存）
│   ├── types.ts            # 类型定义
│   └── styles.css          # 全站样式（深浅色主题 CSS 变量）
└── vite.config.ts
```

## 🛠️ 技术栈

- **React 18 + TypeScript + Vite**（手写配置，无脚手架模板）
- 纯前端静态站，无后端；数据存 localStorage（键 `javaStudyWorkbench.v3`）
- 教程内容为廖雪峰官方教程 2026-10 静态快照，仅作学习用途，版权归原作者
